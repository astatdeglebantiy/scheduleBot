# scheduleBot

A feature-rich Telegram bot designed to help students and faculty manage their academic schedules. This bot, built with `aiogram`, provides an easy way to check lesson schedules, receive notifications for upcoming classes, and stay updated with the latest changes.

## Features

- **View Schedules:** Check the schedule for any day of the week, or look up the schedule for a specific date.
- **Next Lesson Finder:** Quickly find the next lesson for any subject.
- **Customizable Alerts:** Subscribe to notifications for upcoming lessons so you never miss a class.
- **Group Chat Support:** Use the bot in a group chat to manage schedules for a group of students.
- **Admin Panel:** Admins can access usage statistics to monitor the bot's activity.
- **"What's New" Updates:** Stay informed about the latest features and updates to the bot.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/scheduleBot.git
   ```
2. Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the bot with the following command:
```bash
python main.py
```
